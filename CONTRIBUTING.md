# Contributing

pocket3d is open source (AGPL-3.0) but closed to code contributions: it has a single maintainer, and pull requests from outside are closed automatically. You're free to fork it and run your own copy under the license.

What helps, and is very welcome:

- **Bugs:** open an issue with what you did, what you expected and what happened.
- **Ideas and questions:** open an issue.
- **Security problems:** see [SECURITY.md](SECURITY.md). Report them privately, not in a public issue.

To run it yourself, see the [README](README.md#development) and [CLAUDE.md](CLAUDE.md), the map of the code.
